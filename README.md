# gymStore

Bu proje spor salonu ve fitness ekipmanları mini katalog uygulamasıdır. Uygulama içerisinde ürünler listelenebilir, ürün adına göre arama yapılabilir, ürün detayları incelenebilir ve sepete ekleme, çıkarma işlemleri yapılabilir.

## Kullanılan Flutter Sürümü
- Flutter: 3.47.8
- Dart: 3.13.7

## Projeyi Çalıştırma Adımları
1. Proje klasörünü VS Code veya Android Studio ile açın.
2. Terminal üzerinden paketleri indirin:
   flutter pub get
3. Emülatör veya cihaz seçerek uygulamayı başlatın:
   flutter run
